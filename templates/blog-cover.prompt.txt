# CopyApes blog cover generation template
# Size: 1200x630 (16:9). No burned-in title/logo text (reuse across locales).
# Style refs: flat pastel vector / soft line art / light isometric (see team reference set).
# Workflow: generate → assets/inbox/shared/blog/{slug}-cover.png → scripts/optimize_images.py → sync R2

## Style references (intent)
- Flat 2D vector illustration with thin, clean outlines
- Soft pastel palette on a light cream / pale-blue background
- Approachable educational tech mood (not cyberpunk, not photo-real)
- Optional light isometric props; keep scene uncluttered
- Conceptual metaphors via simple objects + network nodes / dashed links / soft glow accents

## Master prompt (fixed)

Create a blog cover image for CopyApes (跟单猿), a crypto copy-trading education brand.

Format: 1200x630, 16:9, horizontal, high-resolution, web-ready.
Style: modern flat vector illustration, thin uniform outlines, minimalist 2D (or gentle isometric props), similar to soft pastel tech explainers — NOT photorealistic, NOT 3D render, NOT dark neon cyberpunk.
Background: light cream or pale blue (#F7F5F0 to #E8F2FA), clean and airy, with soft negative space on one side for optional title overlay.
Color palette: muted pastels — soft blue, mint, peach, lavender, warm grey; low-to-medium contrast; restrained soft glow on a few UI/network accents only.
Composition: one clear central scene or metaphor (~60% of frame); balanced, uncluttered; no dense dashboards; keep edges clean.
Mood: calm, focused, professional, approachable, slightly cautionary educational tone.
Characters (if any): simplified flat characters with minimal facial detail; casual modern clothes; no celebrity likeness.
Typography in image: NONE (no title, no watermark, no logo text, no Chinese/English letters, no headline numbers, no fake UI copy).
Avoid: purple-pink neon gradients, glossy crypto-coin piles, money rain, trophies, rocket-to-moon charts, stock-photo traders, busy exchange screenshots, readable tickers, meme-coin aesthetics, Corporate Memphis exaggeration, dark starfield backgrounds.
Output: crisp vector-like shapes, soft flat shading, minimal noise, suitable as Next.js blog cover and Open Graph image.

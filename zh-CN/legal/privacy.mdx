> 最后更新：2026年7月16日

跟单猿（CopyApes，以下简称“我们”）重视您的隐私。本政策说明我们在提供网站服务与浏览器插件（跟单猿助手）时，如何收集、使用、存储和保护您的个人信息与相关数据。

## 1. 适用范围

本政策适用于 CopyApes 官方网站（copyapes.com）、相关 API 服务，以及 Chrome 浏览器扩展「跟单猿助手」。若您使用我们的网站或插件，即表示您已阅读并理解本政策。

## 2. 我们收集的信息

我们仅收集为提供跟单服务所必要的信息，主要包括：

- 账户信息：注册邮箱、用户名等您主动提供的信息。
- 登录凭证：您在 CopyApes 的登录 token，用于识别账户并保持登录状态。
- 交易所会话数据：在您主动操作时，从 OKX、Binance 等已授权页面读取的 Cookie 与相关请求头，用于跟单 Cookie 同步。
- API 信息：您绑定的交易所 API Key（我们建议使用仅交易权限并设置 IP 白名单）。
- 插件本地数据：语言、主题、Cookie 抓取状态、面板显示偏好等，保存在浏览器本地。
- 使用与日志数据：操作记录、错误日志等，用于保障服务稳定与安全。

## 3. 信息的使用方式

我们收集的信息仅用于以下目的：

- 提供、维护和改进跟单相关功能。
- 同步交易所登录态，执行您发起的 Cookie 抓取与跟单任务。
- 验证账户身份、保障账户与交易安全。
- 在必要时向您发送与服务相关的通知。
- 遵守法律法规要求。

## 4. 浏览器扩展的数据处理

Chrome 扩展「跟单猿助手」按以下方式处理数据。扩展对用户数据的收集与使用遵守 Chrome 网上应用店《用户数据政策》，包括其「有限使用（Limited Use）」要求：

- Cookie 与网络请求权限（cookies、webRequest）：仅在您访问 OKX、Binance 等交易所页面时，读取相关 Cookie 与请求头，用于您主动发起的 Cookie 同步；不会在无关网站上采集数据。
- 本地存储权限（storage）：在您的浏览器本地保存登录 token、语言、主题、Cookie 抓取状态等偏好设置；除您主动提交 Cookie 外，这些数据不会自动上传。
- 标签页权限（tabs、activeTab）：用于识别当前交易所页面，并在您授权时注入操作面板。
- 扩展不收集、不存储您的完整浏览历史，不用于广告投放或用户画像分析。

## 5. 信息共享与披露

我们不会向广告商、数据经纪商或任何无关第三方出售、出租或共享您的个人信息。我们仅在以下情况下与相关方共享必要数据：

- CopyApes 后端服务（api.copyapes.com）：接收您主动提交的账户信息、登录 token、交易所 Cookie 与 API Key，用于提供跟单服务。
- 阿里云（Alibaba Cloud）：作为云基础设施服务商，托管我们的服务器与数据库；数据存储于日本的阿里云数据中心。
- 交易所（OKX、Binance 等）：在您发起跟单或 Cookie 同步时，我们使用您提供的 Cookie 或 API Key 向对应交易所发起请求，以执行您授权的交易操作。
- 经您明确同意的其他情形。
- 法律法规要求，或有权机关依法提出请求。
- 为保护用户、我们或公众的合法权益所必需。

## 6. 数据存储与安全

您的数据存储于日本的阿里云服务器。我们采用合理的技术与管理措施保护您的数据，包括加密存储敏感凭证、访问控制与安全审计。

- API Key、交易所 Cookie 等敏感信息在服务端加密保存。
- 浏览器插件中的偏好设置保存在您设备本地，卸载插件后可清除。
- 账户活跃期间，我们保留为提供服务所必需的数据。
- 您退出登录后，登录 token 立即失效；删除账户后，我们将在 30 天内删除或匿名化处理您的个人数据，法律法规另有要求的除外。

## 7. 您的权利

您有权访问、更正或删除您的账户信息，撤回授权，或停止使用我们的服务。

- 在账户设置中管理 API 绑定与个人信息。
- 在插件中退出登录并清除本地数据。
- 通过下方联系方式请求删除账户及相关数据。
- 如需帮助，请通过网站「联系我们」或发送邮件与我们联系。

## 8. 联系我们

如对本隐私政策有任何疑问，或需要行使您的数据权利，请通过以下方式联系我们：

- 网站：CopyApes 官网「联系我们」页面（copyapes.com）
- 邮箱：service@copyapes.com
- 我们将在收到请求后的 15 个工作日内回复。

## 9. 政策更新

我们可能适时更新本政策。更新后将在本页面公布并修改「最后更新」日期。重大变更时，我们可能通过网站公告等方式通知您。继续使用我们的服务即表示您接受更新后的政策。

## 适用对象

希望使用官方 API 进行稳定跟单的用户。

## 前置条件

- 已在交易所创建 API Key
- 已配置 IP 白名单（如交易所要求）

## 操作步骤

1. 在交易所创建仅含交易与读取权限的 API。
2. 在 CopyApes 填入 API Key / Secret 等信息。
3. 完成连通性检测后创建跟单任务。

## 风险提示

API 权限建议仅开启交易和读取权限，不建议开启提现权限。跟单交易存在亏损风险。

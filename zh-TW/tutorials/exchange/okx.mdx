  <StepItem title="填寫 API 配置資訊">
    出於安全因素考慮，跟單猿要求用戶在申請實盤 API 時，必須填寫固定海外 IP，避免 api 因洩露對您的帳戶造成風險。跟單猿後台有獲取海外固定 IP 的方式渠道。\
    API 必須給予交易權限，否則無法進行交易。 \
    務必記好自己填寫的**Passphrase**，後續需要提交這個欄位資訊！

    ![Okx3 Pn](@asset:tutorials/okx3.png)
  </StepItem>
  <StepItem title="查看 API 資訊並記錄保存">
    返回 API 頻道界面，點擊查看 API 資訊，記錄並填寫到跟單猿後台。

    ![Okx4 Pn](@asset:tutorials/okx4.png)
  </StepItem>

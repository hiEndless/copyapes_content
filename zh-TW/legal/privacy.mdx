> 最後更新：2026年7月16日

跟單猿（CopyApes，以下簡稱「我們」）重視您的隱私。本政策說明我們在提供網站服務與瀏覽器外掛（跟單猿助手）時，如何收集、使用、儲存和保護您的個人資訊與相關資料。

## 1. 適用範圍

本政策適用於 CopyApes 官方網站（copyapes.com）、相關 API 服務，以及 Chrome 瀏覽器擴充功能「跟單猿助手」。若您使用我們的網站或外掛，即表示您已閱讀並理解本政策。

## 2. 我們收集的資訊

我們僅收集為提供跟單服務所必要的資訊，主要包括：

- 帳戶資訊：註冊信箱、使用者名稱等您主動提供的資訊。
- 登入憑證：您在 CopyApes 的登入 token，用於識別帳戶並保持登入狀態。
- 交易所工作階段資料：在您主動操作時，從 OKX、Binance 等已授權頁面讀取的 Cookie 與相關請求標頭，用於跟單 Cookie 同步。
- API 資訊：您綁定的交易所 API Key（我們建議使用僅交易權限並設定 IP 白名單）。
- 外掛本機資料：語言、主題、Cookie 擷取狀態、面板顯示偏好等，保存在瀏覽器本機。
- 使用與日誌資料：操作記錄、錯誤日誌等，用於保障服務穩定與安全。

## 3. 資訊的使用方式

我們收集的資訊僅用於以下目的：

- 提供、維護和改進跟單相關功能。
- 同步交易所登入態，執行您發起的 Cookie 擷取與跟單任務。
- 驗證帳戶身分、保障帳戶與交易安全。
- 在必要時向您發送與服務相關的通知。
- 遵守法律法規要求。

## 4. 瀏覽器擴充功能的資料處理

Chrome 擴充功能「跟單猿助手」按以下方式處理資料。擴充功能對使用者資料的收集與使用遵守 Chrome 線上應用程式商店《使用者資料政策》，包括其「有限使用（Limited Use）」要求：

- Cookie 與網路請求權限（cookies、webRequest）：僅在您造訪 OKX、Binance 等交易所頁面時，讀取相關 Cookie 與請求標頭，用於您主動發起的 Cookie 同步；不會在無關網站上採集資料。
- 本機儲存權限（storage）：在您的瀏覽器本機儲存登入 token、語言、主題、Cookie 擷取狀態等偏好設定；除您主動提交 Cookie 外，這些資料不會自動上傳。
- 分頁權限（tabs、activeTab）：用於識別目前交易所頁面，並在您授權時注入操作面板。
- 擴充功能不收集、不儲存您的完整瀏覽紀錄，不用於廣告投放或使用者畫像分析。

## 5. 資訊共享與揭露

我們不會向廣告商、資料仲介或任何無關第三方出售、出租或共享您的個人資訊。我們僅在以下情況下與相關方共享必要資料：

- CopyApes 後端服務（api.copyapes.com）：接收您主動提交的帳戶資訊、登入 token、交易所 Cookie 與 API Key，用於提供跟單服務。
- 阿里雲（Alibaba Cloud）：作為雲端基礎設施服務商，託管我們的伺服器與資料庫；資料儲存於日本的阿里雲資料中心。
- 交易所（OKX、Binance 等）：在您發起跟單或 Cookie 同步時，我們使用您提供的 Cookie 或 API Key 向對應交易所發起請求，以執行您授權的交易操作。
- 經您明確同意的其他情形。
- 法律法規要求，或有權機關依法提出請求。
- 為保護使用者、我們或公眾的合法權益所必需。

## 6. 資料儲存與安全

您的資料儲存於日本的阿里雲伺服器。我們採用合理的技術與管理措施保護您的資料，包括加密儲存敏感憑證、存取控制與安全稽核。

- API Key、交易所 Cookie 等敏感資訊在伺服端加密保存。
- 瀏覽器外掛中的偏好設定保存在您裝置本機，解除安裝外掛後可清除。
- 帳戶活躍期間，我們保留為提供服務所必需的資料。
- 您退出登入後，登入 token 立即失效；刪除帳戶後，我們將在 30 天內刪除或匿名化處理您的個人資料，法律法規另有要求的除外。

## 7. 您的權利

您有權存取、更正或刪除您的帳戶資訊，撤回授權，或停止使用我們的服務。

- 在帳戶設定中管理 API 綁定與個人資訊。
- 在外掛中退出登入並清除本機資料。
- 透過下方聯絡方式請求刪除帳戶及相關資料。
- 如需協助，請透過網站「聯絡我們」或發送郵件與我們聯絡。

## 8. 聯絡我們

如對本隱私政策有任何疑問，或需要行使您的資料權利，請透過以下方式聯絡我們：

- 網站：CopyApes 官網「聯絡我們」頁面（copyapes.com）
- 信箱：service@copyapes.com
- 我們將在收到請求後的 15 個工作天內回覆。

## 9. 政策更新

我們可能適時更新本政策。更新後將在本頁面公布並修改「最後更新」日期。重大變更時，我們可能透過網站公告等方式通知您。繼續使用我們的服務即表示您接受更新後的政策。

  <StepItem title="API 設定情報を入力">
    セキュリティ上の理由から、CopyApes は実取引 API 申請時に固定の海外 IP の記入を必須としています。API 漏洩による口座リスクを避けるためです。CopyApes 管理画面には海外固定 IP を取得する手段・チャネルがあります。\
    API には取引権限を付与する必要があります。付与しないと取引できません。 \
    自分が設定した **Passphrase** を必ず控えてください。後でこの項目を提出する必要があります！

    ![Okx3 Pn](@asset:tutorials/okx3.png)
  </StepItem>
  <StepItem title="API 情報を確認して記録・保存">
    API チャンネル画面に戻り、API 情報を表示して記録し、CopyApes 管理画面に記入してください。

    ![Okx4 Pn](@asset:tutorials/okx4.png)

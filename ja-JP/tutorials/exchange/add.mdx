  <StepItem title="CopyApes にログインし、「API を追加」をクリック">
    ![Add1 Pn](@asset:tutorials/add1.png)
  </StepItem>
  <StepItem title="対応する取引所を選択し、API 情報を入力">
    <Note title="説明" type="note">
      通常のコピー取引 API を追加する場合は、「読み取り専用」にチェックを入れないでください
    </Note>
    <Note>
      リードトレーダー API（この API に従って同期取引を行う）を追加する場合は、必ず「読み取り専用」にチェックを入れ、その API に IP ホワイトリストを一切設定しないでください。そうしないと使用できません。
    </Note>
    取引所で申請したばかりの API 情報（key と secret）を入力してください。\
    OKX の場合は、申請時に設定したパスフレーズ（PassPhrase）も入力する必要があります
  </StepItem>

</Step>

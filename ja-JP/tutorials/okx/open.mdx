<Step>

  <StepItem title="トレーダーを選択">
    ![Okx5 Pn](@asset:tutorials/okx5.png)

    まず、先物のリードトレーダーを選択していることを確認してください。アドレスバーの **6D9B4445DE8C832B** がそのトレーダー ID です
  </StepItem>
  <StepItem title="トレーダーがポジションを非表示にしているか確認">
    ![Okx6 Pn](@asset:tutorials/okx6.png)

    上記の表示が出る場合、トレーダーはポジション情報を非表示にしており、直接コピーできません。

    コピーするには、まず自分の口座で取引所のコピー取引を行いポジション情報を取得してから、[Cookie コピー](copyapes/vip/cookie) 機能を使ってコピーしてください
  </StepItem>
  <StepItem title="コピー取引タスクを作成">
    「コピー取引を作成」をクリックし、OKX 取引所・公開リードトレードを選択して、トレーダー ID を入力します

    ![Okx7 Pn](@asset:tutorials/okx7.png)
  </StepItem>

</Step>

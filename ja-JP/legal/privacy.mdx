> 最終更新：2026年9月7日

CopyApes（以下「当社」）は、お客様のプライバシーを重視します。本ポリシーは、当社のウェブサイトおよびブラウザ拡張機能「CopyApes アシスタント（跟单猿助手）」を提供するにあたり、個人情報および関連データをどのように収集、利用、保存、保護するかを説明します。

## 1. 適用範囲

本ポリシーは、CopyApes 公式サイト（copyapes.com）、関連 API サービス、および Chrome 拡張機能「CopyApes アシスタント」に適用されます。当社のウェブサイトまたは拡張機能をご利用いただくことで、本ポリシーを確認し理解したものとみなされます。

## 2. 収集する情報

当社は、コピー取引サービス提供に必要な情報のみを収集します。主に以下を含みます。

- アカウント情報：登録メールアドレス、ユーザー名など、お客様が自ら提供する情報。
- ログイン資格情報：アカウント識別とログイン状態維持のための CopyApes ログイントークン。
- 取引所／シグナルソースのセッションデータ：操作開始時に、OKX・Binance・Fomo 等の承認済みページから読み取る Cookie、ページのローカルストレージ内ログイン資格情報（JWT / refresh token 等）、関連リクエストヘッダー（コピー取引の Cookie／資格情報同期用）。
- トレーダー識別子：Fomo 等のトレーダーページ閲覧時に、拡張機能機能を使用した場合、関連 API URL から抽出するトレーダー ID（表示・コピー・コピータスク作成用）。
- API 情報：お客様が紐付ける取引所 API Key（取引権限のみ・IP ホワイトリスト設定を推奨します）。
- 拡張機能のローカルデータ：言語、テーマ、Cookie 取得状態、パネル表示設定など（ブラウザのローカルに保存）。
- 利用・ログデータ：操作記録、エラーログなど（サービスの安定と安全のため）。

## 3. 情報の利用目的

当社が収集する情報は、以下の目的にのみ使用します。

- コピー取引関連機能の提供、維持、改善。
- 取引所／シグナルソースのログイン状態同期、およびお客様が開始した Cookie／資格情報取得、トレーダー ID 認識、コピータスクの実行。
- 本人確認、アカウントおよび取引の安全確保。
- 必要に応じたサービス関連通知の送信。
- 法令遵守。

## 4. ブラウザ拡張機能のデータ処理

Chrome 拡張機能「CopyApes アシスタント」は、以下のとおりデータを処理します。拡張機能によるユーザーデータの収集・利用は、Chrome ウェブストアのユーザーデータポリシー（限定的利用／Limited Use 要件を含む）に準拠します。

- Cookie およびネットワークリクエスト権限（cookies、webRequest）：OKX、Binance、Fomo 等の承認済みサイト訪問時のみ、Cookie・リクエストヘッダーの読み取り、またはコピー設定関連 API リクエストの識別を行います。無関係なウェブサイトではデータを収集しません。
- ページのローカルストレージ読み取り：Fomo 等のサイトで、お客様が同期を開始した際、ページのローカルストレージ内ログイン資格情報（JWT / refresh token 等）を読み取り、資格情報送信に使用します。広告やプロファイリングには使用しません。
- ローカルストレージ権限（storage）：ログイントークン、言語、テーマ、Cookie 取得状態をブラウザにローカル保存。Cookie／資格情報を能動的に送信しない限りアップロードされません。
- タブ権限（tabs、activeTab）：現在の取引所／シグナルソースページを識別し、お客様の許可時に操作パネルを注入。
- 拡張機能は完全な閲覧履歴を収集・保存せず、広告配信やユーザープロファイリングにも使用しません。

## 5. 情報の共有と開示

当社は、広告主、データブローカー、その他無関係な第三者に個人情報を販売、賃貸、共有しません。必要なデータは、以下の場合に限り関係者と共有します。

- CopyApes バックエンドサービス（api.copyapes.com）：お客様が能動的に送信したアカウント情報、ログイントークン、取引所 Cookie／セッション資格情報（JWT / refresh token を含む）、API キーを受け取り、コピー取引サービスを提供。
- アリババクラウド（Alibaba Cloud）：クラウドインフラ提供者としてサーバーとデータベースをホスト。データは日本のアリババクラウドデータセンターに保存。
- 取引所およびシグナルソース（OKX、Binance、Fomo 等）：コピー取引または Cookie／資格情報同期開始時、提供された Cookie、セッション資格情報、または API キーを用いて該当プラットフォームへリクエストし、認可された取引／コピー操作を実行。
- お客様の明示的同意があるその他の場合。
- 法令または権限ある機関の適法な要請がある場合。
- 利用者、当社、または公衆の正当な権利・安全保護に必要な場合。

## 6. データの保存と安全

お客様のデータは、日本のアリババクラウドサーバーに保存されます。当社は、機密資格情報の暗号化保存、アクセス制御、セキュリティ監査など、合理的な技術・組織的措置によりデータを保護します。

- API キー、取引所 Cookie、セッション資格情報などの機密情報はサーバー上で暗号化。
- 拡張機能の設定は端末ローカルに保存され、拡張機能のアンインストールで削除可能。
- アカウント利用期間中、サービス提供に必要なデータを保持。
- ログアウト後、ログイントークンは直ちに無効化。アカウント削除後、法令に別段の定めがない限り、30 日以内に個人データを削除または匿名化。

## 7. お客様の権利

お客様は、アカウント情報へのアクセス、訂正、削除、同意の撤回、またはサービスの利用停止を行う権利を有します。

- アカウント設定で API 連携と個人情報を管理。
- 拡張機能でログアウトし、ローカルデータを消去。
- 下記連絡先を通じてアカウントおよび関連データの削除を請求。
- サポートが必要な場合は、ウェブサイトの「お問い合わせ」またはメールでご連絡ください。

当社は本ポリシーを適宜更新することがあります。更新後は本ページで公表し、「最終更新」日を改定します。重要な変更がある場合、ウェブサイト告知等でお知らせすることがあります。サービスの継続利用は、更新後のポリシーへの同意を意味します。

> 最終更新：2026年7月16日

CopyApes（以下「当社」）は、お客様のプライバシーを重視します。本ポリシーは、当社のウェブサイトおよびブラウザ拡張機能「CopyApes アシスタント（跟单猿助手）」を提供するにあたり、個人情報および関連データをどのように収集、利用、保存、保護するかを説明します。

## 1. 適用範囲

本ポリシーは、CopyApes 公式サイト（copyapes.com）、関連 API サービス、および Chrome 拡張機能「CopyApes アシスタント」に適用されます。当社のウェブサイトまたは拡張機能をご利用いただくことで、本ポリシーを確認し理解したものとみなされます。

## 2. 収集する情報

当社は、コピー取引サービス提供に必要な情報のみを収集します。主に以下を含みます。

- アカウント情報：登録メールアドレス、ユーザー名など、お客様が自ら提供する情報。
- ログイン資格情報：アカウント識別とログイン状態維持のための CopyApes ログイントークン。
- 取引所セッションデータ：お客様が操作を開始した際に、OKX・Binance 等の承認済みページから読み取る Cookie および関連リクエストヘッダー（コピー取引の Cookie 同期用）。
- API 情報：お客様が紐付ける取引所 API Key（取引権限のみ・IP ホワイトリスト設定を推奨します）。
- 拡張機能のローカルデータ：言語、テーマ、Cookie 取得状態、パネル表示設定など（ブラウザのローカルに保存）。
- 利用・ログデータ：操作記録、エラーログなど（サービスの安定と安全のため）。

## 3. 情報の利用目的

収集した情報は、以下の目的にのみ利用します。

- コピー取引関連機能の提供、維持、改善。
- 取引所ログイン状態の同期、およびお客様が開始した Cookie 取得・コピータスクの実行。
- 本人確認、ならびにアカウントおよび取引のセキュリティ確保。
- 必要に応じたサービス関連通知の送信。
- 法令・規制の遵守。

## 4. ブラウザ拡張機能におけるデータ処理

Chrome 拡張機能「CopyApes アシスタント」は、次のとおりデータを扱います。ユーザーデータの収集・利用は、Chrome ウェブストアのユーザーデータポリシー（Limited Use 要件を含む）に準拠します。

- Cookie およびネットワークリクエスト権限（cookies、webRequest）：OKX・Binance 等の取引所ページ訪問時に限り、関連 Cookie とリクエストヘッダーを読み取り、お客様が開始した Cookie 同期に使用します。無関係なサイトでは収集しません。
- ローカルストレージ権限（storage）：ログイントークン、言語、テーマ、Cookie 取得状態などの設定をブラウザローカルに保存します。お客様が Cookie を主動提出する場合を除き、自動アップロードしません。
- タブ権限（tabs、activeTab）：現在の取引所ページを識別し、お客様の許可のもと操作パネルを注入するために使用します。
- 拡張機能は完全な閲覧履歴を収集・保存せず、広告配信やユーザープロファイリングにも使用しません。

## 5. 情報の共有と開示

当社は、広告主、データブローカー、その他無関係な第三者に対し、個人情報を販売・賃貸・共有しません。必要なデータは、次の場合に限り関係者と共有します。

- CopyApes バックエンド（api.copyapes.com）：お客様が主動提出したアカウント情報、ログイントークン、取引所 Cookie、API Key を受け取り、コピー取引サービスを提供します。
- Alibaba Cloud（阿里雲）：クラウドインフラ提供者としてサーバーとデータベースをホストし、データは日本の阿里雲データセンターに保存されます。
- 取引所（OKX、Binance 等）：コピー取引または Cookie 同期を開始した際、提供された Cookie または API Key を用い、対応取引所へリクエストし、承認済みの取引操作を実行します。
- お客様の明示的同意があるその他の場合。
- 法令上の要請、または権限ある当局からの適法な請求。
- ユーザー、当社、または公衆の正当な権利・利益保護のために必要な場合。

## 6. データの保存とセキュリティ

お客様のデータは、日本の阿里雲サーバーに保存されます。当社は、機密資格情報の暗号化保存、アクセス制御、セキュリティ監査など、合理的な技術的・組織的措置によりデータを保護します。

- API Key、取引所 Cookie 等の機密情報はサーバー側で暗号化保存します。
- 拡張機能の設定は端末ローカルに保存され、拡張機能のアンインストールにより削除できます。
- アカウントが有効な間、サービス提供に必要なデータを保持します。
- ログアウト後、ログイントークンは直ちに無効化されます。アカウント削除後は、法令上別段の定めがある場合を除き、30日以内に個人データを削除または匿名化します。

## 7. お客様の権利

お客様は、アカウント情報へのアクセス、訂正、削除、同意の撤回、またはサービス利用の停止を行う権利があります。

- アカウント設定で API 連携と個人情報を管理できます。
- 拡張機能からログアウトし、ローカルデータを消去できます。
- 下記連絡先により、アカウントおよび関連データの削除を請求できます。
- サポートが必要な場合は、サイトの「お問い合わせ」またはメールでご連絡ください。

## 8. お問い合わせ

本プライバシーポリシーに関するご質問、またはデータ権利の行使については、次の方法でご連絡ください。

- ウェブサイト：CopyApes 公式サイトの「お問い合わせ」ページ（copyapes.com）
- メール：service@copyapes.com
- ご請求受領後、15営業日以内に回答します。

## 9. ポリシーの更新

当社は本ポリシーを適宜更新することがあります。更新後は本ページに掲載し、「最終更新」日を改定します。重要な変更がある場合、サイト告知等で通知することがあります。サービスを継続利用することで、更新後のポリシーに同意したものとみなされます。

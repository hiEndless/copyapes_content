Live-account data for popular traders is forwarded after local live copy trading; actual latency is about 5 seconds. Traders come from OKX, Binance, Bicoin, on-chain wallet addresses, and more.

<Step>

  <StepItem title="Select a popular trader">
    This mode is members-only. Select the target trader to copy; trader data can be checked on the corresponding exchange.

    ![Hot Pn](@asset:tutorials/hot.png)
  </StepItem>
  <StepItem title="Create a copy-trading task">
    Select the API you want to use for copying, fill in the task parameters as usual, and start copying.

    <Note>
      This mode cannot obtain the trader’s leverage; you must set it yourself.
    </Note>
  </StepItem>

</Step>

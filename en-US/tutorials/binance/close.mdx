    First make sure you selected a public-domain lead trader. The **4286585043378852352** in the address bar is that trader’s ID.

    To copy private-domain lead trading, first use your own account to copy-trade on the exchange to obtain position data, then use the [Cookie Copy Trading](copyapes/vip/cookie) feature to copy.
  </StepItem>
  <StepItem title="Check whether the trader hides positions">
    ![Bn6 Pn](@asset:tutorials/bn6.png)

    If you see the prompt above, the trader has hidden position information, and you need to use hidden-position copy mode. This mode has about a 2-minute exchange system delay. For zero delay, first use your own account to copy-trade on the exchange to obtain position data, then use the [Cookie Copy Trading](copyapes/vip/cookie) feature to copy.
  </StepItem>
  <StepItem title="Create a copy-trading task">
    Click Create Copy Trading, select Binance, Hidden Live Account, and enter the trader ID.

    ![Bn7 Pn](@asset:tutorials/bn7.png)

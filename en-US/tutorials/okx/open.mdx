  </StepItem>
  <StepItem title="Check whether the trader hides positions">
    ![Okx6 Pn](@asset:tutorials/okx6.png)

    If you see the prompt above, the trader has hidden position information and cannot be copied directly.

    To copy them, first copy-trade with your own exchange account to obtain position data, then use the [Cookie copy trading](copyapes/vip/cookie) feature
  </StepItem>
  <StepItem title="Create a copy-trading task">
    Click Create copy trade, select the OKX exchange and Public lead trading, then enter the trader ID

> 최종 업데이트: 2026년 7월 16일

카피에이프스(CopyApes, 이하 “당사”)는 귀하의 개인정보를 중요하게 생각합니다. 본 방침은 웹사이트 서비스와 브라우저 확장 프로그램(카피에이프스 어시스턴트/跟单猿助手)을 제공할 때 개인정보 및 관련 데이터를 어떻게 수집·이용·저장·보호하는지 설명합니다.

## 1. 적용 범위

본 방침은 CopyApes 공식 웹사이트(copyapes.com), 관련 API 서비스, Chrome 확장 프로그램 「카피에이프스 어시스턴트」에 적용됩니다. 당사 웹사이트 또는 확장 프로그램을 이용하시면 본 방침을 읽고 이해한 것으로 봅니다.

## 2. 수집하는 정보

당사는 카피 트레이딩 서비스 제공에 필요한 정보만 수집하며, 주로 다음을 포함합니다.

- 계정 정보: 등록 이메일, 사용자 이름 등 귀하가 직접 제공하는 정보.
- 로그인 자격 증명: 계정 식별 및 로그인 상태 유지를 위한 CopyApes 로그인 토큰.
- 거래소 세션 데이터: 귀하가 작업을 시작할 때 OKX, Binance 등 승인된 페이지에서 읽는 Cookie 및 관련 요청 헤더(카피 트레이딩 Cookie 동기화용).
- API 정보: 귀하가 연동한 거래소 API Key(거래 권한만 부여하고 IP 화이트리스트 설정을 권장합니다).
- 확장 프로그램 로컬 데이터: 언어, 테마, Cookie 수집 상태, 패널 표시 설정 등(브라우저 로컬에 저장).
- 이용 및 로그 데이터: 작업 기록, 오류 로그 등(서비스 안정성과 보안을 위해).

## 3. 정보 이용 목적

수집한 정보는 다음 목적에만 사용합니다.

- 카피 트레이딩 관련 기능의 제공·유지·개선.
- 거래소 로그인 상태 동기화, 그리고 귀하가 시작한 Cookie 수집 및 카피 작업 수행.
- 신원 확인과 계정·거래 보안 보호.
- 필요한 경우 서비스 관련 알림 발송.
- 관련 법령 준수.

## 4. 브라우저 확장 프로그램의 데이터 처리

Chrome 확장 프로그램 「카피에이프스 어시스턴트」는 다음과 같이 데이터를 처리합니다. 사용자 데이터 수집·이용은 Chrome 웹 스토어 사용자 데이터 정책(Limited Use 요건 포함)을 준수합니다.

- Cookie 및 네트워크 요청 권한(cookies, webRequest): OKX, Binance 등 거래소 페이지 방문 시에만 관련 Cookie와 요청 헤더를 읽어, 귀하가 시작한 Cookie 동기화에 사용합니다. 무관한 사이트에서는 수집하지 않습니다.
- 로컬 저장 권한(storage): 로그인 토큰, 언어, 테마, Cookie 수집 상태 등 설정을 브라우저 로컬에 저장합니다. 귀하가 Cookie를 적극 제출하는 경우를 제외하고 자동 업로드하지 않습니다.
- 탭 권한(tabs, activeTab): 현재 거래소 페이지를 식별하고, 귀하의 승인 하에 조작 패널을 주입하는 데 사용합니다.
- 확장 프로그램은 전체 방문 기록을 수집·저장하지 않으며, 광고 또는 사용자 프로파일링에도 사용하지 않습니다.

## 5. 정보 공유 및 공개

당사는 광고주, 데이터 브로커 또는 무관한 제3자에게 개인정보를 판매·임대·공유하지 않습니다. 필요한 데이터는 다음의 경우에만 관련 당사자와 공유합니다.

- CopyApes 백엔드(api.copyapes.com): 귀하가 적극 제출한 계정 정보, 로그인 토큰, 거래소 Cookie, API Key를 받아 카피 트레이딩 서비스를 제공합니다.
- Alibaba Cloud(알리클라우드): 클라우드 인프라 제공자로서 서버와 데이터베이스를 호스팅하며, 데이터는 일본의 알리클라우드 데이터센터에 저장됩니다.
- 거래소(OKX, Binance 등): 카피 트레이딩 또는 Cookie 동기화를 시작할 때, 제공된 Cookie 또는 API Key로 해당 거래소에 요청하여 승인된 거래 작업을 실행합니다.
- 귀하의 명시적 동의가 있는 그 밖의 경우.
- 법령상 요구 또는 권한 있는 기관의 적법한 요청.
- 사용자, 당사 또는 공중의 정당한 권익 보호에 필요한 경우.

## 6. 데이터 저장 및 보안

귀하의 데이터는 일본의 알리클라우드 서버에 저장됩니다. 당사는 민감 자격 증명의 암호화 저장, 접근 통제, 보안 감사 등 합리적 기술·관리 조치로 데이터를 보호합니다.

- API Key, 거래소 Cookie 등 민감 정보는 서버에서 암호화 저장합니다.
- 확장 프로그램 설정은 기기 로컬에 저장되며, 확장 프로그램 삭제 시 제거할 수 있습니다.
- 계정이 활성인 동안 서비스 제공에 필요한 데이터를 보관합니다.
- 로그아웃 후 로그인 토큰은 즉시 무효화됩니다. 계정 삭제 후 법령에 다른 요구가 없는 한 30일 이내에 개인데이터를 삭제하거나 익명화합니다.

## 7. 귀하의 권리

귀하는 계정 정보에 접근·정정·삭제하거나, 동의를 철회하거나, 서비스 이용을 중단할 권리가 있습니다.

- 계정 설정에서 API 연동과 개인정보를 관리할 수 있습니다.
- 확장 프로그램에서 로그아웃하여 로컬 데이터를 지울 수 있습니다.
- 아래 연락처로 계정 및 관련 데이터 삭제를 요청할 수 있습니다.
- 도움이 필요하면 웹사이트의 「문의하기」 또는 이메일로 연락해 주세요.

본 개인정보 처리방침에 대한 문의 또는 데이터 권리 행사는 다음으로 연락해 주세요.

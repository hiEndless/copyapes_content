> 최종 업데이트: 2026년 9월 7일

카피에이프스(CopyApes, 이하 “당사”)는 귀하의 개인정보를 중요하게 생각합니다. 본 방침은 웹사이트 서비스와 브라우저 확장 프로그램(카피에이프스 어시스턴트/跟单猿助手)을 제공할 때 개인정보 및 관련 데이터를 어떻게 수집·이용·저장·보호하는지 설명합니다.

## 1. 적용 범위

본 방침은 CopyApes 공식 웹사이트(copyapes.com), 관련 API 서비스, Chrome 확장 프로그램 「카피에이프스 어시스턴트」에 적용됩니다. 당사 웹사이트 또는 확장 프로그램을 이용하시면 본 방침을 읽고 이해한 것으로 봅니다.

## 2. 수집하는 정보

당사는 카피 트레이딩 서비스 제공에 필요한 정보만 수집하며, 주로 다음을 포함합니다.

- 계정 정보: 등록 이메일, 사용자 이름 등 귀하가 직접 제공하는 정보.
- 로그인 자격 증명: 계정 식별 및 로그인 상태 유지를 위한 CopyApes 로그인 토큰.
- 거래소/시그널 소스 세션 데이터: 작업을 시작할 때 OKX, Binance, Fomo 등 승인된 페이지에서 읽는 Cookie, 페이지 로컬 저장소의 로그인 자격 증명(JWT / refresh token 등), 관련 요청 헤더(카피 트레이딩 Cookie/자격 증명 동기화용).
- 트레이더 식별자: Fomo 등 트레이더 페이지를 방문하고 확장 프로그램 기능을 사용할 때 관련 API URL에서 추출하는 트레이더 ID(표시·복사·카피 작업 생성용).
- API 정보: 귀하가 연동한 거래소 API Key(거래 권한만 부여하고 IP 화이트리스트 설정을 권장합니다).
- 확장 프로그램 로컬 데이터: 언어, 테마, Cookie 수집 상태, 패널 표시 설정 등(브라우저 로컬에 저장).
- 이용 및 로그 데이터: 작업 기록, 오류 로그 등(서비스 안정성과 보안을 위해).

## 3. 정보 이용 목적

당사가 수집하는 정보는 다음 목적에만 사용합니다.

- 카피 트레이딩 관련 기능 제공·유지·개선.
- 거래소/시그널 소스 로그인 상태 동기화 및 귀하가 시작한 Cookie/자격 증명 수집, 트레이더 ID 인식, 카피 작업 실행.
- 신원 확인 및 계정·거래 보안 보호.
- 필요한 경우 서비스 관련 알림 발송.
- 관련 법령 준수.

## 4. 브라우저 확장 프로그램의 데이터 처리

Chrome 확장 프로그램 「카피에이프스 어시스턴트」는 다음과 같이 데이터를 처리합니다. 확장 프로그램의 사용자 데이터 수집·이용은 Chrome 웹 스토어 사용자 데이터 정책(제한적 사용/Limited Use 요건 포함)을 준수합니다.

- Cookie 및 네트워크 요청 권한(cookies, webRequest): OKX, Binance, Fomo 등 승인된 사이트 방문 시에만 관련 Cookie·요청 헤더를 읽거나 카피 설정 관련 API 요청을 식별합니다. 무관한 웹사이트에서는 데이터를 수집하지 않습니다.
- 페이지 로컬 저장소 읽기: Fomo 등 사이트에서 귀하가 동기화를 시작할 때 페이지 로컬 저장소의 로그인 자격 증명(JWT / refresh token 등)을 읽어 자격 증명 제출에 사용합니다. 광고나 프로파일링에는 사용하지 않습니다.
- 로컬 저장소 권한(storage): 로그인 토큰, 언어, 테마, Cookie 수집 상태를 브라우저에 로컬 저장합니다. Cookie/자격 증명을 능동적으로 제출하지 않는 한 업로드되지 않습니다.
- 탭 권한(tabs, activeTab): 현재 거래소/시그널 소스 페이지를 식별하고, 귀하의 인가 시 조작 패널을 주입합니다.
- 확장 프로그램은 전체 브라우징 기록을 수집·저장하지 않으며, 광고 또는 사용자 프로파일링에 사용되지 않습니다.

## 5. 정보 공유 및 공개

당사는 광고주, 데이터 브로커 또는 무관한 제3자에게 개인정보를 판매·임대·공유하지 않습니다. 필요한 데이터는 다음의 경우에만 관련 당사자와 공유합니다.

- CopyApes 백엔드 서비스(api.copyapes.com): 귀하가 능동적으로 제출한 계정 정보, 로그인 토큰, 거래소 Cookie/세션 자격 증명(JWT / refresh token 포함), API Key를 수신하여 카피 트레이딩 서비스를 제공합니다.
- 알리바바 클라우드(Alibaba Cloud): 클라우드 인프라 제공자로서 서버와 데이터베이스를 호스팅하며, 데이터는 일본의 알리바바 클라우드 데이터센터에 저장됩니다.
- 거래소 및 시그널 소스(OKX, Binance, Fomo 등): 카피 트레이딩 또는 Cookie/자격 증명 동기화를 시작할 때, 제공된 Cookie, 세션 자격 증명 또는 API Key로 해당 플랫폼에 요청하여 인가된 거래/카피 작업을 수행합니다.
- 귀하의 명시적 동의가 있는 기타 경우.
- 법령 또는 권한 있는 기관의 적법한 요청이 있는 경우.
- 사용자, 당사 또는 공중의 정당한 권익·안전을 보호하기 위해 필요한 경우.

## 6. 데이터 저장 및 보안

귀하의 데이터는 일본의 알리바바 클라우드 서버에 저장됩니다. 당사는 민감 자격 증명의 암호화 저장, 접근 통제, 보안 감사 등 합리적인 기술·관리적 조치로 데이터를 보호합니다.

- API Key, 거래소 Cookie, 세션 자격 증명 등 민감 정보는 서버에서 암호화 저장됩니다.
- 확장 프로그램 환경설정은 기기 로컬에 저장되며, 확장 프로그램 제거 시 삭제할 수 있습니다.
- 계정 이용 기간 동안 서비스 제공에 필요한 데이터를 보관합니다.
- 로그아웃 후 로그인 토큰은 즉시 무효화되며, 계정 삭제 후 법령에 다른 규정이 없는 한 30일 이내에 개인데이터를 삭제하거나 익명화합니다.

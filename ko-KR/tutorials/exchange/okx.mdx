    보안상의 이유로 CopyApes는 실거래 API 신청 시 고정 해외 IP 입력을 필수로 합니다. API 유출로 계정에 위험이 생기는 것을 방지하기 위함입니다. CopyApes 백엔드에는 해외 고정 IP를 얻는 방법·채널이 있습니다.\
    API에는 거래 권한을 부여해야 하며, 그렇지 않으면 거래할 수 없습니다. \
    직접 입력한 **Passphrase**를 반드시 기억해 두세요. 이후 이 필드 정보를 제출해야 합니다!

  <StepItem title="해당 거래소를 선택하고 API 정보를 입력">
    <Note title="설명" type="note">
      일반 카피 트레이딩 API를 추가할 때는 “읽기 전용”을 선택하지 마세요
    </Note>
    <Note>
      리드 트레이더 API(이 API를 따라 동기 거래를 수행)를 추가하는 경우 반드시 “읽기 전용”을 선택하고, 해당 API에 IP 화이트리스트를 추가하면 안 됩니다. 그렇지 않으면 사용할 수 없습니다.
    </Note>
    방금 거래소에서 신청한 API 정보(key와 secret)를 입력하세요.\
    OKX인 경우, 신청 시 설정한 패스프레이즈(PassPhrase)도 입력해야 합니다
  </StepItem>
